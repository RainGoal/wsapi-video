# 账号与后台提交生命周期验收（r11）

日期：2026-10-18。本轮延续已批准的自由画布产品范围，修复 r10 审查发现的账号生命周期问题，以及充值、项目和后台配置提交的已确认竞态。没有恢复分镜功能。

## 实施结果

- 请求捕获会话版本。旧会话的迟到 401 不再使新身份退出；当前受保护的账户接口 401 能触发登录过期。初始化/重试 `/me` 同时校验请求序号与会话版本。
- 登录与 `/me` 等待当前页面尚未结束的 Cookie 变更请求，涵盖登录、退出、改密和撤销会话的成功/失败响应；等待结束后重新检查请求是否仍有效。解决旧退出响应清除新登录 Cookie 的当前页面内顺序问题，不外推为跨标签或跨设备协调。
- 认证内容按会话重新挂载，侧栏钱包在该边界内读取。切换账号时，新余额尚未加载或失败均不展示旧账号余额。
- 改密成功后结束原会话，即使已经离开账户页面仍执行；迟到结果不能结束新会话。保留本地草稿和提交恢复，在登录卡片内显示正常提示，语言切换时重新翻译。
- 退出同步防重；服务端 401 仍能完成本地退出，浏览器存储清理异常不阻断退出。其他服务错误保留当前身份并显示错误。
- 充值创建和订单核查同步防重，并校验页面与会话。创建期间锁定支付方式、关闭、取消、Esc 和遮罩关闭；离开钱包后，旧回执不触发收银台跳转。
- 项目保存/删除期间锁定弹窗和表单，卸载后忽略迟到 UI 回执。归档成功立即保留新 revision，DELETE 失败后用最新 revision 重试。
- 后台配置保存与检测共享同步操作锁，每轮挂载和请求有独立身份。卸载后的成功、错误和 finally 不改变新页面，旧 finally 不解除新操作的锁；reload 在操作期间早退。

上述页面保护不取消服务端已经开始的写入，不能把忽略 UI 回执当作服务端回滚或完整幂等保证。

## 验证

最终源码统一前端 **130/130 通过、0 skip**，TypeScript、Prettier、第三方许可与 Vite 生产构建通过。新增 40 项包含：API 会话边界 9 项、账户/认证/充值动作 19 项、项目动作 7 项、后台配置操作 5 项。

动作回归从当前组件源码提取真实函数，用受控 Promise 验证同一轮重复操作、失败重试、卸载及会话变化。API 回归执行实际请求封装，覆盖响应解析延迟、同令牌重新登录、受保护账户接口、多个 401、Cookie 屏障动态追加及失败释放。它们不代替真实后端端到端验收。

最终构建浏览器 **14 项限定检查**通过：

1. A 账户显示自己的可用/冻结积分。
2. 受保护会话列表 401 结束 A。
3. 旧退出响应 pending 时，B 登录暂不发送。
4. 旧 Cookie 删除响应后才建立 B Cookie，B 余额 pending 时不显示 A 缓存。
5. A 迟到的 401/成功响应及 B 余额失败均不使 B 退出或泄露 A 余额。
6. 同一轮两次改密只发送一次请求。
7. 离开账户页后改密成功仍结束原会话，保留草稿/恢复，并显示正常登录提示。
8. 390px 英文登录提示无横向溢出，语言切换可点击。
9. 切回中文重新翻译会话提示。
10. C 登录清除前次提示并加载 C 的积分。
11. 充值只创建一个夹具订单，pending 时锁支付方式和所有关闭入口。
12. 浏览器返回离开钱包后，迟到收银台回执不跳转或改变新页面。
13. 退出同步防重，503 保留当前身份与 Cookie，并显示可重试错误。
14. 退出 401 且草稿删除抛错时仍结束本地身份，其他账号草稿/恢复不受影响。

全部页面、静态构建与业务 API 由隔离夹具接管：32 次 API 请求，7 次夹具写请求；真实业务写、真实模型调用、生成费用均为 0。pageerror、未处理 API、外部请求均为 0，context/browser 已关闭。没有登录或修改常驻服务。

准备阶段出现定位器及同文档导航不匹配，已按实际可访问树和显式重载修正。浏览器还实际发现会话提示遮挡语言按钮及存储的提示未随语言更新，均已修改源码并重建；14 项记录全部使用最终 `index-C73BaLhd.js` 重新执行。中间观察与最终构建在 JSON 的 harnessNotes 中区分，不将中间结果算入最终检查。
