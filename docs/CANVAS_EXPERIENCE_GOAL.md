# 画布体验改良目标（2026-10-19）

用户确认以 infinite-canvas 为交互参考，完善当前自由图片/视频创作画布。

## 验收范围

- 默认移动：空白左拖平移，节点直接选择/拖动；取消独立选择箭头，修饰键临时框选，保留追加多选和中键移动。
- 节点以素材内容为主，名称、端口和动作随交互展示；单击打开节点创作区，拖动不误开面板，双击成品预览。
- 底栏直建空组、多选打组/解组快捷键；组标题、成员数、拖入高亮和吸附、就地改名、边框尺寸调整；整组移动/复制，解组保留成员。
- 外观面板：浅色/深色、线格/点阵/空白、图片信息开关；个人主题记忆，项目背景和信息开关随云端画布、草稿及撤销保存。
- 独立视图区：缩放滑杆、百分比、适合画布、小地图导航、操作帮助。
- 保留当前节点生成/再次生成、任务和素材历史、参考角色、计费与服务端权限校验。

## 实施与验证

1. 并行完善外观、视图控制、项目状态存储；统一主编辑器手势及分组交互。
2. 运行前端逻辑测试、类型/格式/生产构建及涉及的后端测试。
3. 本机隔离测试画布验证默认手势、分组、连线、主题/保存恢复、视图导航和响应式；验证期间不调用真实模型或支付。
4. 完成变更审查、更新验证证据，沿用 master 与版本标签的双架构镜像发布流程。
