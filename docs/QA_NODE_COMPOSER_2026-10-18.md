# 节点就地创作验收

日期：2026-10-18。目标版本：v0.1.6。

## 用户确认的体验

- 新建图片/视频节点先显示占位卡，单击节点后在附近展开提示词、模型、素材与参数；点击空白或 Esc 收起，重新选中恢复该节点草稿。
- 双击空白打开类型菜单；输出端口拖至空白后选择图片或视频，创建下游节点和引用。创建及连线可一次撤销。
- 参考素材以缩略图展示，可从项目素材库、上传或画布选取；视频模型支持时可指定普通参考、首帧、尾帧。
- 显式获取报价并确认后提交，后台继续运行；每次形成独立结果节点，归档后可继续引用。

## 复用与平台边界

来源固定为 `basketikun/infinite-canvas` 的 `3a6b64b602ad062b29fac66902ed18a7ef5fd9dc`。除既有画布/连线/几何组件，本轮按固定源码适配创建菜单、空媒体占位、节点工具条、提示词面板及可视化参考条，来源清单见 `web/THIRD_PARTY_NOTICES.md`；保留 MIT 原文与可见作者归属。

原版是完整应用，本轮没有把它称为可直接安装的 SDK。平台节点外壳、选择与历史整合、云端保存继续由现有适配层负责；没有引入其个人 Key/模型直连、插件、Agent 或本地项目主存储。没有新增运行依赖、数据库迁移或分镜流程。

`metadata.generationDraft` 保存当前草稿；历史任务输入与生成结果来源保持独立。复制内部节点关系时重映射来源 ID，避免将来源边误当新参考。已生成媒体的原任务快照不会被后续创作覆盖。草稿里的参考和首尾帧进入服务端素材归属检查及引用保护。

提交仍经过平台 `/quotes → /tasks`。恢复记录额外保存原 `source_node_id`，向任务 API 仍只发送原报价和去重键。确认结果在同一个浏览器恢复锁内先交付画布、再清记录；项目已卸载时保留恢复记录。移动、连线、撤销及切换面板不触发生成或账务操作。

新增回归包括草稿安全读取/参数归一化、显式移除参考和帧角色恢复、权威提示词不被笔记反复插回、媒体源和历史结果快照隔离、来源关系复制、原节点恢复身份、先交付后清记录，以及跨账号草稿素材保存拒绝和引用删除保护。

浏览器检查覆盖：

1. 占位节点不自动弹表单，单击就地编辑，切换节点恢复独立草稿与规格。
2. 双击类型菜单；拖线续建；一次撤销同时移除新节点和边；菜单创建后立即 Ctrl+Z 可用。
3. 画布拾取形成引用；修改输入使报价失效；确认前任务数不变，确认后创建独立结果。
4. 模拟任务交付后显示归档结果，保留来源边；实际 MP4 夹具的控件区域可以打开创作，Shift 单击可取消选择。
5. 视频首尾帧进入正确字段，8 秒/1080p 的夹具报价正确；不支持音频开关的商品不发送 audio。
6. 模拟回执丢失、跨节点恢复、离开项目后再恢复：共 5 次任务 POST（含同键恢复）只产生 3 个唯一夹具任务，来源节点正确。
7. 上传中切换节点，完成后参考仍归原节点；迟到报价不覆盖新节点。
8. 拖动中失焦后继续移动鼠标不续拖，一次撤销恢复位置；多选后普通单击回到单选。
9. 输入区域滚轮不缩放画布；参数/素材 Portal 浮层避让视口；窄屏无横向页面溢出；云端画布重载恢复草稿。

浏览器请求全部由合成 HTTPS 主机的夹具拦截，没有启动应用服务。页面异常、未处理端点、外部请求记录均为空；真实业务写入、外部模型调用及生成费用均为零，浏览器与上下文已关闭。本轮不代表真实商品、支付、SMTP 或目标服务器部署验收。

最终受测构建为 `index-pe7sKjyd.js` / `index-kvQL_vMS.css`。Vite 提示主 JS 压缩前超过 500 kB，构建成功；本轮没有为此引入额外拆包重构。
