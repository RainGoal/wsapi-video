# 自由画布图片与视频创作调整（r10）

日期：2026-10-17。依据用户最新要求：不需要分镜，在画布中自由创建图片、视频，并通过连线处理关系。参考 [infinite-canvas 固定版本](https://github.com/basketikun/infinite-canvas/tree/3a6b64b602ad062b29fac66902ed18a7ef5fd9dc)。

## 实施结果

- 工作台只保留画布和素材视图，移除分镜组件、入口及生成调用。旧分镜深链回到画布；历史素材引用仍保留，不删除后端记录或迁移。
- 画布工具栏和空态提供图片、视频入口，立即创建带 `metadata.generationKind` 的创作节点并打开对应设置。
- 图片支持编辑图片、生成视频；视频支持继续创作及原生播放控件。每次受理保留独立结果和来源连线，旧作品继续可用。
- 素材、文字笔记和分组可连接到创作节点；笔记自动带入提示词，重新打开时按完整段落去重。生成来源线不作为参考输入处理。
- 图生视频按商品能力使用首帧或普通参考；首尾帧不会重复进入普通参考，支持帧的模型切换保留角色，不支持时恢复为普通参考。
- 受理后保存创作节点的模式、模型与提示词。保留原报价确认、提交恢复、云端保存、任务派生状态和画布撤销边界。
- 从素材库加入画布时避让已有节点，仍可自由拖动。登录及项目引导文案同步收敛到图片、视频和画布。

## 本轮验证

前端统一 `npm test`：**90/90 通过，0 skip**；TypeScript、Prettier、第三方许可检查与 Vite 生产构建通过。创作专项 9 项、素材引用专项 7 项和先前完成的调账恢复专项 17 项均包含在统一检查中。

浏览器 **23 项限定检查**通过，包括两种创作入口、键盘连线、参考带入、首尾帧与模型切换、图片生成、图片继续生成视频、结果来源、跨视图撤销重做、刷新恢复、旧深链及 390px 英文界面。没有 pageerror、未处理 API 或外部网络请求，context/browser 已关闭。

所有页面及业务响应均由隔离夹具接管：20 次业务写请求包含 3 次报价和 4 次任务提交，只形成 3 个唯一夹具任务；真实业务写、真实模型调用与生成费用均为零。没有登录或修改常驻服务。不能把这 23 项检查理解为完整商业端到端验收。

测试准备阶段修正了分页夹具缺少 total/limit/offset、任务夹具 ID 不符合服务端格式，以及自动化标签/属性面板选择器。无效任务回执被提交恢复保护保留，修正夹具后使用原键恢复同一任务；没有删除恢复键或创建替代提交。浏览器实际发现的素材重叠问题已修复，并用最终构建重新检查新素材避让。

本轮没有验证真实模型视频播放或 S3 归档；原生视频控件的加入不代表这些外部链路已验收。本轮未修改后端，未重跑后端测试；后端 r9 历史证据继续按原范围保留。
