# 当前节点生成验收

日期：2026-10-18。发布目标：v0.1.7。

## 本轮行为

按用户最新要求，图片/视频生成直接更新发起生成的媒体节点。节点 ID、标题、位置、尺寸、分组和连线保留；排队、生成、归档、失败和成品显示在当前节点，再次生成继续更新它。任务中心与素材库仍保存历史记录，不修改历史输入、价格和账务。

受理新任务时清除旧预览及错误，只展示当前任务的状态和已归档素材。相同任务重复受理不改变画布；服务端创建时间与此前任务 ID 防止旧回执覆盖较新结果。提交恢复仍使用原报价、原去重键及原节点身份；已删除节点不会被迟到回执重新创建。旧 Config 和无来源的历史入口保留兼容路径，不迁移既有画布布局。

导入图片已选作参考时，原素材在生成前后继续保留在草稿选择里。新成品不会自动成为自身参考，分组输入也排除接收节点自身。生成中的节点仍可编辑下一次参考输入，已受理任务输入保持原快照。

补充修复快速完成竞态：任务列表首次刷新已经是 completed / ready，但对应素材尚未进入前端列表时，沿用原轮询补取素材；素材到达后停止轮询。正常生成输出由服务端任务引用保护，用户不能删除仍被引用的作品。

新增回归覆盖原节点身份及连线保留、同时间/纳秒级旧任务排序、重复回执、删除来源、当前任务归档素材、旧自图参考保留、输出不自动自引用、跨媒体类型草稿以及分组排除自身。

浏览器覆盖：

1. 图片受理、生成中、归档和成品始终在原节点，节点数量与连线不增加。
2. 再次生成立即用状态替换旧预览，完成后替换成品，刷新恢复同节点与草稿。
3. 视频首帧、时长和分辨率正确进入请求，归档 MP4 在原视频节点可播放。
4. 模拟回执丢失后从另一节点恢复，仍归原视频节点；同键恢复不创建新任务。
5. 较旧同时间回执不覆盖较新的图片；失败后再次生成清除旧错误。
6. 提交中删除节点，回执到达不复活节点；撤销只恢复画布，不新发生成请求。
7. 已有导入图片直接在本节点替换成品，保留已选择的原图参考。
8. 原图和旧视频仍在素材库，窄屏与英文面板正常，帮助文案说明当前节点生成。
9. 首次响应即完成的图片与视频均补取缺失素材；素材补齐后再观察两个轮询周期，没有继续请求。

全部浏览器请求在合成 HTTPS 主机拦截，没有启动应用服务。两阶段共 12 次夹具任务 POST（含两次同键恢复）对应 10 个唯一任务。页面异常、未处理端点及外部请求均为零；真实业务写入、外部模型调用和费用为零，浏览器与上下文已关闭。该记录不替代真实模型或用户服务器部署验收。
