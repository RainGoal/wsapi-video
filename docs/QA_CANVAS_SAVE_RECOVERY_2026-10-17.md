## 待选择恢复稿与旧基线

在上述副本建立两个浏览器 context：使用同一已验证用户会话 Cookie，但独立 localStorage；没有复制另一 context 的草稿。通过普通 UI 产生真实冲突：

2. B 刷新后出现恢复选择窗口。编辑器 DOM 数为 0，“新建生成”禁用；另以真实 canvas GET 回执延迟验证加载期间同一按钮也禁用。没有发出报价或任务创建。
