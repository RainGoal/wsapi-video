# 素材来源与引用位置

原始需求为素材页“引用位置”和“区分上传文件和生成结果”，以及受引用素材删除时的解除/保留说明。

## 来源

现有 Asset 的非空 `task_id` 表示生成结果，空值表示上传文件。来源任务使用平台本地任务 ID；浏览器不读取服务凭证或供应商对象地址。生成结果可进入本人任务详情查看不可变输入与收费事实，来源标签本身不创建任务。

## 只读引用接口

`GET /api/v1/assets/{id}/references?limit=25&offset=0` 要求账号会话。未知、软删除或其他账号素材均返回 404；未登录返回 401。分页使用现有规则：limit 默认 25、范围 1–100，offset 默认 0、上限 10000000，非法或重复分页参数返回 422。

成功沿用统一响应：

```json
{
  "code": "ok",
  "data": {
    "items": [{
      "project_id": "prj_example",
      "project_name": "示例项目",
      "project_status": "active",
      "project_deleted": false,
      "owner_type": "shot",
      "owner_id": "shot_example",
      "owner_label": "镜头标题"
    }],
    "total": 1,
    "limit": 25,
    "offset": 0
  }
}
```

查询来自已有 asset_references，只返回当前账号项目的元数据，包含自己的归档和软删除项目。按 project_id、owner_type、owner_id 升序分页；超出末页返回同条件 total 和空 items。引用可在其他设备变更，列表是读取时事实，刷新后重新核对，不把已显示结果当成删除许可。

| owner_type | owner_id / 含义 | 用户可采取的动作 |
| --- | --- | --- |
| canvas | 项目 ID，画布整体引用；不是某个节点 ID | 在项目画布中查找并移除该素材的所有引用，保存 |
| shot | 具体镜头 ID；owner_label 为现存镜头标题，可为空 | 在对应镜头移除参考、候选及选定关系，保存 |
| cover | 项目 ID，封面引用 | 更换或清除项目封面并保存 |
| task | 平台任务 ID，可能是输入素材或生成结果的来源关联 | 查看历史任务；不可修改已接受任务的输入或手动解除历史关联 |

已归档项目显示归档标记，修改前需恢复；已删除项目不提供可用项目跳转。历史任务、已删除项目及长期留存的引用按已公布政策由运营核查，此接口不提供清理/解绑操作。

响应不含邮箱、提示词、object key、签名地址或服务凭证。此接口不改项目 revision、引用、任务、余额、流水或文件；读取失败不能显示为“没有引用”。真正删除仍由 DELETE 接口在事务中锁素材并检查全部引用，不能凭浏览器空列表绕过。

当前实现和实际验收以对应 QA 记录为准；接口契约不代表已更新运行中的服务或完成生产验收。
